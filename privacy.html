Privacy Policy

Last updated: October 16, 2026

rclone-backup is a personal application used to back up files from my home server to my own Google Drive account.

The application uses Google OAuth to access Google Drive for uploading, listing, and managing backup files.

OAuth credentials are stored locally in the rclone configuration on my server.

Backup file content and filenames are encrypted before being uploaded to Google Drive.

The application does not use advertising, analytics, or tracking, and does not send files to a separate application server.

Access is restricted to the application owner.
